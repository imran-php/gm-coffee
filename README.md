# GM COFFEE

Адаптивный статический сайт кофейни: витринное меню из 10 позиций с уникальными фотографиями, категории, поиск, сортировка, избранное, выбор объёма, корзина, доставка / самовывоз и оформление через WhatsApp.

## Открыть локально

Запустите из этой папки `python3 -m http.server 8765` и откройте http://localhost:8765.

## GitHub Pages

Содержимое этой папки можно разместить в корне репозитория и включить Pages для ветки main, папка `/ (root)`. Сборка и серверная часть не требуются. Все пути относительные и работают в подпапке репозитория.

## Настройки

- `js/config.js`: контакты и условия доставки.
- `js/menu.js`: напитки, варианты, цены и фотографии.
- `js/app.js`: интерфейс и формирование сообщения WhatsApp.
- `css/refinement.css`: оформление.
- `assets/`: оптимизированные изображения WebP.

WhatsApp: +7 (928) 020-04-42. Сайт готовит сообщение с заказом и открывает WhatsApp. Покупатель самостоятельно нажимает «Отправить». Сайт не подтверждает получение сообщения или оплату автоматически. При блокировке всплывающего окна остаётся ссылка для перехода.

Корзина и избранное хранятся в localStorage. Поля оформления остаются в памяти вкладки; не сохраняются на сервере или в localStorage.

Изображения созданы встроенным Imagegen для оформления сайта; это не фотографии реальной продукции кофейни. Каждая карточка использует уникальное изображение. Сведения о составе уточняются при заказе. Адрес точки самовывоза и оплата согласуются в WhatsApp.
