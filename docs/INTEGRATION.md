# Оформление заказа

Сайт работает без сервера. `sendWhatsAppOrder` в `js/app.js` формирует сообщение с позициями, вариантами, количеством, суммой, способом получения, контактами и адресом. Открывается ссылка `https://wa.me/79280200442?text=…`. Покупатель отправляет сообщение самостоятельно. Резервная ссылка остаётся на экране, если браузер блокирует новое окно.

Автоматический приём платежей и отслеживание курьера не подключены. Подтверждение, время и оплата согласуются в WhatsApp.
